This page reports the systematic extension behind it — 18 plans, four briefs, K=6, a random baseline, the D0–D4 ladder, a diversity–quality frontier check, and a stage-by-stage failure taxonomy. It is a snapshot of non-frozen extensions, not a replacement for the frozen v1.0 catalogue.

Diversity–quality frontier

A single mean point can hide the trade-off. For every cell, bench/pareto.py rebuilds the same valid pool QD saw and samples 2,000 seeded K=6 subsets. The best sampled subset is an oracle, not another practical selector: it asks whether the greedy archive is actually on the frontier.

Failure taxonomy

P/G/S/O follows the term plan: P perception, G planning, S solver, O output/build. IR-level stress set

Four deterministic perturbations of the R1 image IR test the M3/M4 stack, not perception: rot90 swaps room width/depth, coarse rounds dimensions, nosize removes object sizes, and scale90 shrinks the shell by 9%. All keep room names, so the same briefs apply.

What is not tested

  • P-stage perception. Live image perception is now a separate modelbench arm (12 images; Claude/GPT vision; DeepSeek text-only); the v1.3 main table still holds cached IR fixed, so the two are not mixed.
  • LLM-direct and system ablations. LLM-direct and the multi-model comparison are now run (1,536 runs; Claude/GPT/DeepSeek; build 1,506/1,536; brief-effect 81.7%); the four matched system ablations (no-library, no-IR, no-solver) remain future work.
  • Human preference. The protocol is pre-registered; no participants have been run, so no preference number is claimed.
  • Full render validation. The main matrix is build-valid; only a small M6 subset has renders. The stress set has a four-candidate spot check.
  • Generalisation. Nine of eighteen plans are real, and R4–R9 are manual transcriptions, not fresh VLM outputs.
  • Planning errors inside the IR. The G column is a brief-effect proxy; because the IR is held fixed, a wrong room count or missing object in the transcript is not re-scored here.
